# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting: go to the
[Security tab](../../security) of this repository and click
**"Report a vulnerability"**. Only the maintainers can see reports
submitted this way.

We will acknowledge your report as soon as possible and keep you informed
of the progress. Please give us a reasonable amount of time to address the
issue before any public disclosure.

## Scope

- Vulnerabilities in the code of this repository.
- Leaked credentials or personal data accidentally committed to this
  repository (please report these privately as well).
