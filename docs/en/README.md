# AC9 Cloth Retopo User Manual (English)

An add-on for retopologizing garment meshes made in CLO / Marvelous Designer, on Blender, while staying in 2D (the flattened pattern shape).
This folder is the English manual.

## How to read this

First-time readers should go through [01_concepts.md](01_concepts.md) →
[02_install.md](02_install.md) → [03_workflow.md](03_workflow.md) in that order.
Without the terminology in place — especially the division of labor between Guide and Retopo — it's hard to tell which object a given button acts on.
Once the flow is in your head, [04_panels.md](04_panels.md) is meant to be used as a dictionary you look things up in.
If something isn't working, check [06_troubleshooting.md](06_troubleshooting.md) first.
Everything in this manual is written from the add-on's code. Anywhere that couldn't be confirmed from the code is explicitly marked "(to be confirmed)".
