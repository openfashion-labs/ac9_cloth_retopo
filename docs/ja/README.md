# AC9 Cloth Retopo ユーザーマニュアル（日本語）

CLO / Marvelous Designer で作った衣装メッシュを、Blender 上で 2D（型紙のかたち）のままリトポロジーするためのアドオンです。
このフォルダはその日本語マニュアルです。

## 目次

| ファイル | 内容 |
|---|---|
| [01_concepts.md](01_concepts.md) | 何のためのツールか。Guide / Retopo / Flat SK / Mirror / Final という用語と、「2Dが正、3Dは鏡」の考え方 |
| [02_install.md](02_install.md) | 対応バージョン、インストール、サイドバーの場所、**Experimental tools** スイッチ、shapely について |
| [03_workflow.md](03_workflow.md) | 最初から最後までの一本の流れ。各ステップで「何を見れば次へ進めるか」 |
| [04_panels.md](04_panels.md) | パネル別リファレンス。ボタン / すること / 前提 / 結果 |
| [05_experimental.md](05_experimental.md) | Experimental（既定で非表示）の機能と、なぜ未完成なのか |
| [06_troubleshooting.md](06_troubleshooting.md) | 止まったとき・何も起きないときの対処 |

## 読み方

はじめての人は [01_concepts.md](01_concepts.md) →
[02_install.md](02_install.md) → [03_workflow.md](03_workflow.md) の順に読んでください。
用語（とくに Guide と Retopo の役割分担）が入っていないと、どのボタンがどちらのオブジェクトを触るのかが分かりません。
流れが頭に入ったあとは [04_panels.md](04_panels.md) を辞書として引く使い方を想定しています。
うまく動かないときは [06_troubleshooting.md](06_troubleshooting.md) を先に見てください。
このマニュアルの記述はすべてアドオンのコードから起こしています。コードから確認できなかった箇所は「（要確認）」と明示しています。
